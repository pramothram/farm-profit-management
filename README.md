# 🌾 Farm Profit Management

A web-based **Farm Profit Management System** developed using **Python and Django** to help farmers manage cultivation expenses, harvest details, income, and calculate the overall **profit or loss** from farming activities.

## ✨ Features

* 🔐 **User Registration & Login**

  * Secure user authentication
  * Only registered users can access their farm management dashboard

* 🌱 **Farm / Planting Management**

  * Add and manage planting details
  * Record planting date and crop-related information

* 💰 **Expense Management**

  * Record day-to-day farming expenses
  * Add expense date, purpose, and amount
  * View and manage expense records

* 🌾 **Harvest Management**

  * Add harvest details
  * Record harvest date, quantity, unit, and selling price
  * View harvest information

* 📊 **Profit & Loss Calculation**

  * Automatically calculate total farming expenses
  * Calculate total income from harvest
  * Display the final profit or loss

* 📱 **Responsive User Interface**

  * Clean and attractive dashboard
  * User-friendly navigation
  * Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Django
* **Database:** PostgreSQL
* **Authentication:** Django Authentication
* **Deployment:** Render
* **Version Control:** Git & GitHub

## 🎯 Project Objective

The main objective of this project is to provide farmers with a simple digital solution for tracking **farming expenses and harvest income**, reducing manual calculations and making it easier to understand the overall financial performance of their farming activities.
